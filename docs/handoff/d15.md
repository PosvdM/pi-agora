## PR 描述草稿：D15 子代理额度与上下文

### 范围

- daemon 发出的任务书以“你是子代理。”开头。`agora_task` 工具说明要求任务范围明确、附必要接口与结论、并行前确定接口、机械性工作用 medium、完成后不追加新工作。
- `spawn.skills` 按名字选择用户 skill，默认空名单，可由配置按档位设置默认值；显式名单覆盖默认值，下级只能取上级的子集。生产启动保留 `-ns`，仅通过 `--skill` 加载选中的路径，不自动加载项目 skill。
- 白名单 skill 目录向文件工具提供只读授权；explore 可读 `SKILL.md`，名单外没有额外授权；implement 可以用 shell 执行 skill 脚本，shell 不承诺路径隔离。
- schema v4 保存名单与解析路径、额度恢复信息及逐请求用量。迁移前进行 SQLite 一致性备份；记录关联任务、代、会话、运行与请求，并对重复事件去重。status/result 提供单任务和任务树汇总，result 提供指定代汇总，并保留旧会话统计字段。
- 可识别的 429 额度错误使任务进入 `quota_paused`，不计失败、不占推理名额。保留原会话与代数；到重置时间后默认向直接上级发送通知，附暂停任务的上下文大小；可配置自动续跑。恢复父任务不会隐式恢复下级，停止子树会停止暂停中的下级。
- pi 专有的 skill 解析、CLI 参数、usage 和额度错误提取位于 driver；任务层及数据库处理 Harness 中立字段。

### 自行决定

1. 复用现有 recover 的 resume/abandon，额度暂停不增加 generation。需要换模型时先停止再派活，避免改变现有 replace 接口和继承语义。
2. 缺少重置时间时不猜测恢复时刻，也不自动续跑；发送 `task:quota_unknown`，由上级核对后手动恢复。
3. `contextTokens` 使用服务最近报告的非零输入上下文（input + cacheRead + cacheWrite）；错误返回零用量时保留最后已知大小。树上下文为各任务最近值之和，不把历史输入累计当作上下文大小。
4. 服务未单独提供 reasoning token 时记为 0，不从 output 反推。result.usage 保留旧 tokens/cost 等字段，并追加中立汇总；generationUsage 单独提供指定代统计。
5. skill 名字沿用 pi 的命名规范。相同真实目录的别名去重；不同目录同名拒绝，不隐式选择其一。`skillDirectories` 可显式替换默认查找目录。
6. 额度错误必须同时含明确额度码和 429；仅含普通限流或丢失状态码的友好提示仍走原失败路径。相对 retry_after 按事件接收时间换算，reason 使用稳定错误码。

### 已知限制

- 无法从 RPC 取得的 provider 内部重试、隐藏 reasoning token 和错误私有字段不推测。额度识别不是所有 provider 错误格式的通用解析器。
- 记账在助手请求结束事件到达时写入；进程在事件发出前被杀时，尚未报告的消耗无法准确记账。token 预算和上下文阈值策略属于后续阶段。
- 白名单控制自动加载和文件工具授权，不屏蔽已经位于原允许根内的普通文件；implement shell 仍能访问同一用户有权访问的路径，不是沙箱。
- CLI、pane 的专用用量展示未在本改动中实现。
- 本分支仍含 1b 基线的通知 404 失败，须在合入作者的收尾分支后再次运行全量测试。
